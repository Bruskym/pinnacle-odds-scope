# 🎯 Pinnacle Drop Detector

Sistema de monitoramento de alta frequência para detecção de drops significativos nas odds de futebol da Pinnacle.

## 📋 Especificações Técnicas

| Especificação | Detalhes |
|---------------|----------|
| **Esporte** | Futebol |
| **Mercado** | Moneyline (1X2) |
| **Bookmaker** | Pinnacle |
| **Tipo** | Monitoramento de alta frequência |
| **Linguagem** | Python 3.8+ |
